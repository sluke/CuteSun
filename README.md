# CuteSun Plugin for Typecho

CuteSun 是一个为 Typecho 博客设计的萌系交互挂件插件。它完全采用纯 HTML、CSS 和原生 JavaScript 实现，无需外部图片资源或库，加载速度极快且高度可定制。

## ✨ 特性

- **轻量化**: 仅通过代码绘制，零外部请求。
- **多种风格**: 内置四种截然不同的视觉风格。
- **趣味交互**: 每个挂件都支持点击触发状态切换或循环变色。
- **纯粹设计**: 保持简约、童趣的设计感。

## 🎨 内置风格

### 1. 阳光小萌 (Cute Sun)
- **默认**: 开启状态，一个笑脸盈盈、光芒四射的金黄色太阳。
- **点击**: 切换至冷静状态，收起光芒，表情变得安静。

### 2. 像素小猫 (Pixel Cat)
- **设计**: 参考 Claude Code 风格的极致简约像素艺术。
- **点击**: 在 **橙、黄、白、黑、棕** 五种经典猫咪配色间循环切换。

### 3. 像素咖啡 (Pixel Coffee)
- **默认**: 一杯正冒着热气的浓郁咖啡（动态蒸汽效果）。
- **点击**: 喝完手中的咖啡，杯子变空且不再冒热气。重新点击可续杯。

### 4. 勋章铭牌 (Kanji Badge)
- **设计**: 经典的圆形勋章风格。
- **内容**: 循环显示极具辨识度的汉字：**“龟”、“界”、“悟”、“超”**。
- **特色**: 边框颜色会根据字体颜色自动同步（如红色的“界”、金色的“超”等）。

## 🚀 安装指南

1. 下载插件源码。
2. 将 `CuteSun` 文件夹上传至 Typecho 根目录下的 `/usr/plugins/` 目录。
3. 登录 Typecho 后台，点击 **设置 -> 插件**。
4. 找到 **CuteSun** 并点击 **激活**。

## ⚙️ 插件设置

在插件激活后，点击 **设置**（或配置）：
- **Widget Style**: 从下拉/单选框中选择您喜欢的挂件风格（阳光、像素猫、咖啡或勋章）。
- 点击 **保存设置** 即可在博客首页右下角看到效果。
